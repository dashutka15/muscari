# Мускари

Многостраничный учебный сайт салона красоты на PHP и MySQL. Точка входа — `index.php`. Все страницы, `config.php` и `database.sql` находятся в корне папки `muscari`.

## Запуск через Open Server

1. Распакуйте папку `muscari` целиком в каталог проектов Open Server. В Open Server Panel 6 это обычно `C:\OSPanel\home\muscari`. В Open Server 5 используйте каталог сайтов, например `domains`.
2. Перезапустите панель. Включите PHP 8.3 с расширением `pdo_mysql` и модуль MySQL 8.0. В Open Server 6 проект использует `.osp/project.ini`. Если PHP 8.3 не установлен, укажите в этом файле установленный PHP 8.1 или новее. В Open Server 5 укажите папку `muscari` как корень домена в настройках.
3. В phpMyAdmin откройте «Импорт» и выберите файл `muscari/database.sql`. Скрипт создаст базу `muscari`, таблицы и заполнит каталог. Для импорта нужны права на создание базы. Если phpMyAdmin отсутствует, выполните в консоли Open Server:
   ```cmd
   osp use MySQL-8.0
   mysql -h MySQL-8.0 -u root < "C:\OSPanel\home\muscari\database.sql"
   ```
   Укажите путь к своему файлу. При установленном пароле MySQL добавьте `-p`.
4. Откройте `http://muscari.local/index.php` через Open Server 6 или адрес, назначенный домену в вашей панели. Если сервер обслуживает общий каталог сайтов, используйте адрес вида `http://localhost/muscari/index.php`. Двойной клик по файлу PHP не запускает сайт.

Если при записи или загрузке админ-панели появляется ошибка базы, проверьте импорт и настройки `config.php`. По умолчанию используются база `muscari`, порт `3306`, пользователь `root` и пустой пароль. При пустом `db_host` сайт пробует `MySQL-8.0` и `127.0.0.1`. Если ваш модуль называется иначе, впишите его хост явно. В Open Server 6 это обычно имя модуля, например `MySQL-8.4`.

Документация Open Server Panel: <https://github.com/OSPanel/OpenServerPanel/wiki/Документация>.

## Альтернатива — Docker Desktop

1. Запустите Docker Desktop.
2. Откройте терминал в папке `muscari` и выполните `docker compose up --build -d`.
3. Откройте <http://localhost:8080/index.php>. База импортируется автоматически при создании нового тома.
4. Для остановки используйте `docker compose down`. Чтобы сохранить заявки и отзывы, не добавляйте `-v`.

## Обновление существующего сайта

1. Сохраните резервную копию папки проекта и экспорт базы через phpMyAdmin.
2. Замените файлы сайта файлами из этого архива. Структура папки осталась прежней. Если меняли подключение к базе или пароль администратора, перенесите свои значения в `config.php`.
3. В phpMyAdmin выберите существующую базу `muscari`, откройте «Импорт» и загрузите **`upgrade-accounts.sql`**. Он добавляет таблицу пользователей и связи записей и отзывов с аккаунтами. Существующие услуги, мастера, акции, заявки и отзывы сохраняются. Повторный импорт безопасен.
4. Откройте сайт. Адреса файлов оформления содержат версию: браузер загрузит новые стили автоматически. Файл `accounts.css` отвечает за кабинет, вход и регистрацию — обязательно скопируйте его вместе с остальными файлами.

Для нового проекта импортируйте только `database.sql`: новая схема уже включена в него. В Docker с существующим томом выполните `docker compose exec -T db mysql -u root -proot_muscari_local muscari < upgrade-accounts.sql` (проверьте пароль в `docker-compose.yml`).

## Личный кабинет клиента

В шапке всех страниц есть «Войти в аккаунт». На странице входа доступна регистрация по имени, телефону +7, электронной почте и паролю. После регистрации вход происходит автоматически. Для следующего входа используйте почту и пароль. Пароли клиентов хранятся в виде хешей.

В кабинете доступны:

- текущие записи и статусы подтверждения;
- ближайшая запись и количество выполненных посещений;
- история выполненных и отменённых записей;
- повторная запись на доступную в каталоге услугу;
- отмена своей будущей записи, пока она новая или подтверждённая;
- редактирование имени и телефона, их автоматическая подстановка в форму записи;
- собственные отзывы со статусом модерации;
- выход из аккаунта.

Записывайтесь после входа, чтобы новая заявка появилась в кабинете. Гостевая запись по-прежнему доступна. Старые гостевые заявки видны администратору; они не присваиваются аккаунту по совпадению номера телефона. Администратор меняет статус заявки в прежней панели: после отметки «Выполнена» визит попадает в историю клиента. Отзывы из кабинета также поступают в прежнюю очередь модерации.

## Админ-панель

Нажмите «Войти в аккаунт» в шапке сайта и введите данные администратора. После входа откроется прежняя панель управления. Прямая ссылка `admin.php` также работает, но сначала требует входа.

- Логин — `admin`
- Пароль — `Muscari-local-2026!`

Логин и пароль можно изменить в `config.php`. Админ-панель управляет заявками, отзывами, услугами, акциями и мастерами. Номер в форме проверяется в браузере и на сервере. Данные сохраняются в MySQL.

## Структура

```text
muscari/
├── index.php, services.php, offers.php, team.php, reviews.php, contacts.php
├── login.php, register.php, logout.php, account.php
├── admin.php, dashboard.php
├── config.php, bootstrap.php, auth.php, layout.php
├── api/
│   └── index.php
├── assets/
├── app.js, styles.css
├── database.sql, upgrade-accounts.sql
├── Dockerfile, docker-compose.yml
└── README.md
```

`database.sql` — локальная база со стартовыми данными. Повторный импорт сохраняет изменения, заявки и отзывы. Проект предназначен для локального учебного запуска.

## Исправление отправки заявок

В этой версии перед отправкой формы обновляется защитный токен сеанса. Обновлены адреса JavaScript-модулей, чтобы браузер не использовал старый код отправки. Замените файлы из архива, сохранив свои настройки config.php. Повторный импорт базы для этого исправления не требуется.
